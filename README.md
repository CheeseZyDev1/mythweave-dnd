# Mythweave Online Tabletop

เว็บโต๊ะ D&D ออนไลน์พร้อมห้องผู้เล่น แผนที่โลก ตัวละคร เสียงประกอบ ลำดับเทิร์น และผลทอยเต๋าที่ซิงก์พร้อมกัน

## เปิดเล่นบนเครื่อง

ต้องมี Node.js 20 ขึ้นไป จากนั้นรัน:

```powershell
npm install
npm start
```

เปิด `http://localhost:3000` ผู้เล่นที่ใช้รหัสห้องเดียวกันจะเข้าสู่ล็อบบี้เดียวกัน เลือกเริ่มเกมใหม่หรือเล่นต่อจากเซฟ กดพร้อม แล้วรอให้โฮสต์เริ่มการผจญภัย ทุกคนจะเห็นเทิร์น แชต ตำแหน่งบนแผนที่ และผลทอยเดียวกัน

ตัวอย่างลิงก์ห้อง:

```text
http://localhost:3000/#room=MOON-742
```

## นำขึ้นเว็บ

โปรเจกต์มี `render.yaml` สำหรับสร้าง Web Service บน Render:

1. นำโฟลเดอร์นี้ขึ้น GitHub
2. ใน Render เลือก New Blueprint และเลือก repository
3. หลัง deploy ให้ส่ง URL ที่มี `#room=รหัสห้อง` ให้เพื่อน

Blueprint ถูกกำหนดเป็น `plan: free` จึงไม่มีค่า compute ตราบใดที่ใช้งานอยู่ภายในข้อจำกัดของแผนฟรี (ผู้ให้บริการอาจขอการยืนยันบัญชี) หากไม่มีผู้ใช้งานเกิน 15 นาที เซิร์ฟเวอร์ฟรีจะพักและการเข้าใช้งานครั้งถัดไปอาจรอประมาณหนึ่งนาที

เซิร์ฟเวอร์ต้องรองรับ WebSocket จึงไม่ควร deploy เป็น static site อย่างเดียว

## การซิงก์ในห้อง

- เซิร์ฟเวอร์เป็นผู้สุ่มผลเต๋าเพียงครั้งเดียว
- ห้องมีโฮสต์ สถานะพร้อม และปุ่มเริ่มเกมเมื่อทุกคนพร้อม
- โฮสต์เลือกเริ่มใหม่หรือส่งสถานะแคมเปญล่าสุดให้ห้องเพื่อเล่นต่อ
- เฉพาะเจ้าของเทิร์นปัจจุบันเท่านั้นที่ทอยและจบเทิร์นได้
- ผลดิบ โบนัส ผลรวม และแอนิเมชันจะถูกส่งให้ทุกคน
- เมื่อผู้เล่นออกจากห้อง ลำดับเทิร์นจะปรับให้อัตโนมัติ

## ทดสอบ multiplayer

ขณะเปิดเซิร์ฟเวอร์อยู่ ให้รัน:

```powershell
npm run test:multiplayer
```

หมายเหตุ: สถานะห้องออนไลน์ปัจจุบันเก็บในหน่วยความจำของเซิร์ฟเวอร์ หากเซิร์ฟเวอร์รีสตาร์ต ห้องออนไลน์จะเริ่มใหม่ ส่วนตัวละครและบันทึกส่วนตัวในเบราว์เซอร์ยังคงอยู่ ขั้นถัดไปควรเชื่อม PostgreSQL/Supabase เพื่อเซฟแคมเปญข้ามเครื่องแบบถาวร
